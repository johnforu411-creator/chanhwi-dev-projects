# Shoulder OS V2.1 — 후기 기반 개선 및 사용 흐름 점검

## 이번에 구현한 것

- 재활 BEST 6와 개별 재활 운동을 일반 운동 기록이 아닌 단계형 가이드 화면으로 실행합니다. 세트/시간 진행, 운동 목적, 수행 순서, 주의 큐, 흔한 실수, 통증 기준을 한 흐름에서 확인하고 완료 후 통증 기록은 선택할 수 있습니다.
- 테니스 기록을 날짜별로 추가·수정·삭제할 수 있습니다. 시간, 강도, 연습/게임/레슨 구분, 서브 여부, 어깨 통증, 메모를 저장해 캘린더에서도 볼 수 있습니다.
- 홈 위젯의 재활 바로가기도 안내형 재활 세션으로 연결했습니다.

## 참고한 사용자 경험과 반영점

- [Hevy 사용자 리뷰](https://play.google.com/store/apps/details?gl=us&hl=en&id=com.hevy)는 운동 설명/애니메이션, 사용자 운동·루틴과 기록 이력을 유용하게 평가하는 한편, 일부는 기능 제한과 과거 기록 가져오기 문제를 언급합니다. 여기서는 핵심 재활 설명을 세션 안으로 가져오고, 기록 종류·메모를 사용자가 직접 입력하도록 했습니다.
- [Hevy 사용자 토론](https://www.reddit.com/r/Hevy/comments/1vay936/this_app_is_absolute_perfect/)에서는 운동 중 화면을 벗어나 이력/옵션으로 가기 어렵거나, 기존 기록 가져오기에 실패했다는 불편이 나옵니다. 이번 범위에서는 타이머를 포함한 운동 실행의 흐름을 단순화했지만, 과거 앱에서의 데이터 가져오기는 아직 구현하지 않았습니다.
- 어깨·근골격 재활 앱 이용자 연구([PLOS Digital Health, 2024](https://journals.plos.org/digitalhealth/article?id=10.1371/journal.pdig.0000626))에서는 영상과 명확한 설명이 올바른 동작에 대한 안심을 돕는 반면, 로그인/설정 부담, 기술 문제, 운동 적합성, 자신감·동기 저하가 지속 사용의 장애로 보고됩니다. 이를 반영해 반복 입력 대신 바로 시작되는 안내 세션과 통증 입력 선택지를 적용했습니다. 실제 영상 안내, 재활 전문가와의 검토, 사용성 검증은 아직 필요합니다.
- [TennisKeeper 리뷰](https://apps.apple.com/us/app/tenniskeeper-swings-scores/id1097388824?see-all=reviews)는 경기 시간·건강 데이터 연동, 상대 전적, 라켓/스트링 사용 시간 같은 맥락 정보를 반기는 반면, 스윙 분석용 손목 기기 착용이 불편하다는 피드백도 있습니다. 따라서 이번 테니스 편집은 코트에서 입력 부담이 적은 짧은 구조화 기록(세션 종류·시간·강도·서브·통증·메모)으로 두었고, 센서 착용을 요구하지 않습니다.

후기는 앱스토어/플레이스토어의 개별 공개 리뷰 및 게시글이고 전체 사용자를 대표하는 조사 결과는 아닙니다. 재활 연구의 응답률 한계도 있으므로, 기능 우선순위를 정하는 정성적 신호로만 사용했습니다.

## 제가 따라가며 발견한 문제와 개선점

기존 화면 흐름을 코드와 저장/조회 경로 기준으로 따라가 보니, 재활 운동을 선택해도 일반 웨이트 기록표로 넘어가 치료 순서·주의사항이 운동 도중에는 떨어져 있었습니다. 테니스는 빠른 기록 추가만 가능하고 과거 기록의 수정/삭제와 구체 메모가 없어, 캘린더에 쌓인 기록을 고치기 어려웠습니다. 이 두 단절을 각각 안내형 재활 세션과 캘린더 내 기록 편집으로 연결했습니다.

새 흐름은 `오늘/위젯 → 재활 안내 → 세트 진행 → 선택적 통증 기록`, `캘린더 날짜 → 테니스 추가/수정/삭제 → 캘린더 표시 확인`입니다. 실제 Android 기기에서 손으로 조작한 검증은 하지 못했고, Flutter 정적 분석과 자동 데이터 흐름 테스트로 검증했습니다. 따라서 터치 영역, 작은 화면 레이아웃, 타이머 알림/화면 꺼짐, 위젯의 실기기 동작은 설치 후 확인 대상입니다.

## 다음에 더하면 좋은 순서

1. 재활 세션의 중단/재개, 운동 사이 휴식 타이머, 오늘 완료 표시와 지난 기록 재열람.
2. 통증이 기준을 넘을 때 안전한 중단 안내, 개인별 운동 적합성/진행단계 설정. 의료진 확인 없는 자동 난이도 증가는 피하는 것이 좋습니다.
3. 테니스 월간/주간 총시간, 연습 대비 경기 비율, 통증 추세, 상대·코트 필드(원할 경우), 라켓/스트링 사용 시간.
4. Body Calendar에서 내보낸 데이터의 가져오기/백업, 위젯 크기와 표시 설정.
5. 실제 사용자 몇 명으로 1주일 사용성 테스트: 운동을 시작하기까지 걸린 시간, 기록 수정 성공률, 재활 세션 중 이탈 지점, 통증 입력이 과하게 부담스럽지 않은지 확인.
