## 결론

원본 Flutter/Dart 소스는 발견되지 않았지만, APK에서 기존 앱의 오프라인 운동 데이터, 운동 이미지, 글꼴, 기능별 소스 경로, Drift 테이블 이름과 주요 필드 흔적을 복구했다. 기존 앱은 재활 수행·평가·기록 중심이며, 웨이트 세트 기록을 최우선으로 하는 V2 요구사항과는 중심 구조가 다르다.

따라서 V2는 기존 앱을 억지로 복원하기보다 새 Flutter 프로젝트로 재구축하고, APK에서 복구한 검증 가능한 운동 데이터와 이미지 자산을 선택적으로 이관하는 것이 안전하다. 제품의 첫 화면과 기본 기록 흐름은 바디캘린더형 빠른 운동 기록을 중심으로 설계하고, 재활·통증·테니스·치료 기록은 같은 운동 타임라인에 연결한다.

## 8. 데이터 마이그레이션 계획

중요한 제약이 있다. APK에는 사용자 개인 DB가 포함되지 않으며, 원래 서명용 개인 키도 없다. 같은 패키지명으로 새 APK를 만들더라도 서명이 다르면 Android가 기존 앱 위에 업데이트 설치를 허용하지 않는다.

따라서 기본 계획은 다음과 같다.

1. 기존 V1.4 APK와 복구 자산을 읽기 전용 백업으로 보존한다.
2. V2는 별도 패키지명(예: `com.personal.shoulder_os`)으로 설치해 기존 앱을 지우지 않는다.
3. 기존 앱에서 내보낸 백업 파일 또는 `shoulder_rehab.sqlite`가 제공되면 V2 가져오기 기능으로 변환한다.
4. 레거시 16개 테이블을 V2의 운동, 세션, 루틴, 통증, 다음날 반응, 치료 테이블로 매핑한다.
5. 매핑할 수 없는 필드는 원문 JSON 메타데이터로 보존하고 마이그레이션 로그에 남긴다.
6. 운동명·ID 중복은 표준 운동 ID 우선, 사용자 편집본은 커스텀 운동으로 보존한다.
7. 실제 사용자 DB가 없으면 V1.4 운동 58개와 이미지 59개만 시드로 가져오고 새 기록 DB로 시작한다.
8. 마이그레이션은 원본을 수정하지 않고 복사본에서 수행하며, 성공 건수와 제외 건수를 사용자에게 보여준다.

## 제품 우선순위 확정

V2의 메인은 바디캘린더형 운동 기록이다. 앱 실행 후 가장 강한 행동은 `오늘 운동 시작`이며, 운동 선택과 세트 기록은 1~2회 터치에 가깝게 설계한다. 재활, 통증, 테니스, 치료는 별도 앱처럼 분리하지 않고 같은 날짜·운동 세션·다음날 반응에 연결한다.

## BodyCalendar 1.18.13 참고 분석

사용자가 제공한 XAPK를 읽기 전용 UX 참고자료로 분석했다. 패키지는 `com.bodyplusone.android.bodycalendar`, versionCode 284, minSdk 28, targetSdk 36이며 Flutter 앱이다. 해당 앱의 브랜드, 코드, 이미지, 음원, 문구는 V2에 복사하지 않는다.

컴파일된 기능 구조에서 확인한 참고 포인트:

- 캘린더가 단순 기록 조회가 아니라 날짜별 운동 편집의 중심 화면이다.
- 운동 선택에 일반, 분류, 최근, 폴더형 진입점이 있다.
- 선택 직후 오늘 운동 미리보기와 기존 데이터 덮어쓰기 확인 흐름이 있다.
- 세트 수정 화면에 전용 숫자 키보드, 빠른 증감, 세트 추가/삭제, 일괄 수정이 있다.
- 최근 세트 복사, 이전 이력 불러오기, 실패 세트, 슈퍼세트가 분리되어 있다.
- 운동 타이머, 휴식 타이머, 슈퍼세트 휴식 타이머가 세트 화면에 결합되어 있다.
- 운동별 상세에 이력, 정보, 기록 차트가 분리되어 있다.
- 루틴에는 편집, 최근 이력 불러오기, 비교, 운동 미리보기가 있다.
- 일간/월간 캘린더, 히트맵, 날짜별 운동 묶음, 볼륨/세트/운동시간 통계가 있다.
- 최근값, 최고값, 1RM, 볼륨을 빠르게 비교하는 기록 요약을 사용한다.

V2에 가져올 UX 원칙:

1. 첫 행동은 운동 시작 또는 최근 운동 이어하기
2. 운동 선택은 최근·즐겨찾기·루틴·카테고리 순으로 빠르게
3. 지난 세트가 오늘 입력칸 바로 위 또는 안에 표시
4. 중량과 횟수는 전용 숫자 입력 및 큰 증감 버튼 제공
5. 세트 완료 즉시 휴식 타이머 시작
6. 완료된 세트는 한눈에 구분되고 실수로 누른 경우 즉시 되돌리기 가능
7. 운동 종료 시 통증은 한 번만 묻고 세트별 통증은 선택 기능
8. 캘린더에서 웨이트·재활·테니스·통증·치료를 한 날짜에 함께 표시
9. 기록 상세에서 최근값·최고값·총 볼륨·다음날 어깨 반응을 함께 비교
10. 고급 기능은 데이터 모델에 준비하되 초기 화면은 세트 기록에 집중

Shoulder OS만의 차별화:

- 세트 기록에 `어깨 통증 추적 대상` 플래그를 연결한다.
- 운동 종료 통증과 다음날 반응을 해당 운동 목록에 자동 연결한다.
- 재활 등척성은 중량/횟수 대신 힘 비율·유지시간·세트 타이머를 사용한다.
- 테니스는 시간·강도·서브 여부를 같은 캘린더 이벤트로 저장한다.
- 치료와 MRI는 운동 분석에서 원인으로 단정하지 않고 타임라인 문맥으로 함께 보여준다.
- Phase별 BEST 운동은 일반 즐겨찾기와 분리한다.
