# Tennis Vision

## 상태

현재 GitHub에 확보된 기준선은 `tennis_vision_v0.html` 로컬 프로토타입입니다.

현재 구현:
- 영상 업로드/재생
- 단식/복식 설정
- 선수명 및 상대 전적 로컬 저장
- 스코어보드
- 샷/구질/방향/속도/바운드/에러 기록
- 편집 강도 설정
- CSV / JSON / 인쇄용 리포트
- 경기 분석 요약 UI

## 실행 방법

브라우저에서 `tennis_vision_v0.html` 을 열면 됩니다. 별도 라이브러리 설치가 필요하지 않습니다.

## APK

Google Drive의 `App Builds - Install` 폴더:
- `TennisVision-v0-debug.apk`

현재 확보된 APK와 HTML 프로토타입이 같은 소스 트리에서 만들어졌는지는 재검증이 필요합니다.
