# Tennis AutoCut — Auto-first rebuild

기존 수동 중심 흐름을 **자동 편집 → 사람 검수 → MP4 출력**으로 바꾼 Android 재구축 버전입니다.

## 제품 흐름
1. 영상 열기
2. 자동 분석 시작
3. 장시간 저활동 구간을 자동 제외 후보로 계산
4. 자동 KEEP 구간을 재생하며 수동 경계 보정/제외/복구
5. Media3 Transformer로 KEEP 구간을 순서대로 연결해 MP4 출력

자동 분석 전에는 수동 시작/끝 편집 UI를 노출하지 않습니다.

## 현재 자동 엔진
첫 버전은 고정 카메라 테니스 영상의 축소 프레임 움직임을 샘플링해 **확실히 긴 저활동 구간만 보수적으로 제거**합니다. 공 추적, 샷 분류, 점수 판정은 아직 하지 않습니다. 과도한 자동 삭제를 막기 위해 제외 비율 안전 상한을 둡니다.

## 빌드
- AGP 8.9.2 / Gradle 8.11.1 / JDK 17
- compile/target SDK 35 / minSdk 29
- Kotlin 2.0.21
- Media3 1.11.1

현재 브랜치는 기존 APK와 충돌하지 않도록 별도 applicationId로 설치됩니다.
